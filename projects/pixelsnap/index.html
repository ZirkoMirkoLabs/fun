  1. 01Drop an AI image, paste it, or try an example.
  2. 02Pick one of 8 versions. Tweak grid, palette or edges if you like.
  3. 03Try effects. One is already running on your pixels. Click another, or Surprise me. Apply a frame, or take a GIF or sprite sheet.
  4. 04Take a PNG at any scale, transparent PNG, SVG, palette, or a 16–128 px pack.

USE WITH AI AGENTS

Run PixelSnap locally as an MCP tool for Claude, Codex or Cursor. Your agent can snap images, list effects, apply any of the 27 by ID, and write new effects as validated JSON recipes.

  1. Connect. Claude Code: claude mcp add pixelsnap -- + a command from this section.
  2. Choose. list_effects returns every ID. Copy agent call above gives you the current one.
  3. Apply. preview_effect shows a frame, apply_effect writes a PNG, GIF or sprite sheet.
  4. Create. validate_effect checks a recipe. Save recipe or import one above.
GitHub & setup ↗Agent & recipe guide

FROM GITHUB Snap, preview and apply all 27 effects. Needs uv and Node 18+.

uvx --refresh --from "git+https://github.com/ZirkoMirkoLabs/fun#subdirectory=desktop/pixelsnap" pixelsnap mcp

FROM A LOCAL CHECKOUT WITH EFFECTS Run from the fun repository root. Needs uv and Node 18+.

uv run --isolated --no-project --with "./desktop/pixelsnap[mcp]" pixelsnap mcp
